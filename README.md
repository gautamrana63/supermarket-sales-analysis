# supermarket-sales-analysis
# 🛒 Supermarket Sales Analysis

This project analyzes a dataset of supermarket sales using Python. It explores patterns in customer behavior, payment methods, product performance, and city-level trends using data visualization and exploratory data analysis (EDA).

 Repository Contents

- `supermarket_sales_analysis.ipynb` – Jupyter Notebook with the full analysis
- `supermarket_sales.csv` – Dataset
- `README.md` – Project overview

Key Insights

- Total Customers: 1000
- Gender Split: 501 Female / 499 Male
- Highest Average Gross Income: Home & Lifestyle
- Most Common Payment Method: Ewallet
- City with Most Customers: Yangon
- Best Average Rating: Food & Beverages

 Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook
